⚙️ Falta configurar el login

Este panel usa Firebase Authentication para el login real (no un PIN escondido en el código). Para activarlo:

  1. Entrá a console.firebase.google.com y creá un proyecto (gratis).
  2. En Authentication → Sign-in method, activá Correo/contraseña.
  3. En Authentication → Users, creá manualmente tu usuario admin (no hay pantalla de registro pública).
  4. En Configuración del proyecto → General, copiá el objeto firebaseConfig.
  5. Pegalo en este archivo, al principio del <script type="module">, reemplazando los valores TU_....
